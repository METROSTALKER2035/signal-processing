# Лабораторна робота №11. Двовимірне перетворення Фур'є та детектування контурів на зображеннях

**Дисципліна:** Обробка сигналів та зображень
**Виконав:** Афанасьєв Сергій, група КІ 24-1
**Варіант:** 2

## Мета

Опанувати теоретичні засади спектрального аналізу цифрових зображень у частотній області на основі двовимірного дискретного перетворення Фур'є (2D-FFT), дослідити процеси частотного центрування, розрахунку амплітудного й фазового спектрів, реалізувати синтез ідеальних та гаусових частотних фільтрів низьких і високих частот, а також вивчити роботу просторових градієнтних операторів першого порядку (Собеля, Шарра) та оптимального детектора контурів Кенні з адаптивним вибором порогів гістерезису.

## Завдання (варіант 2)

| Параметр | Значення |
|----------|----------|
| Радіус ідеального ФНЧ D0 | 50 пікс. |
| Параметр гаусових фільтрів σf | 35 пікс. |
| Розмір ядра Собеля | 3 |
| Пороги Canny [T_low, T_high] | [60, 180] |

Знімка плати у завданні немає, тому півтонову сцену 512×512 (доріжки, площадки, решітка виводів, кільця, напис та чотири слабкі подряпини контрастом 12, 25, 45, 80) згенеровано в коді.

## Запуск

Потрібен Python 3.10+.

```bash
python3 -m venv venv

# Windows (PowerShell)
venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python lab11_fft2d_edges.py
```

Скрипт створює сцену в `data/`, виводить у консоль перевірки спектра, таблиці фільтрації, градієнтів і Canny, а графіки зберігає в `figures/`. Ноутбук `lab11_fft2d_edges.ipynb` відкривається в Jupyter, VS Code або Google Colab; запускати його потрібно з каталогу проєкту.

## Короткі результати

- Парсеваль виконується (1.656190·10⁹ з обох боків), зворотне ШПФ відновлює кадр з похибкою 1.1·10⁻¹³; у постійній складовій 63.85 % потужності.
- ILPF (D0 = 50): PSNR 23.86 дБ, кільця Гіббса, вихід −8.7…253.2; GLPF (σf = 35): PSNR 25.45 дБ, без кілець, вихід 39.1…214.7; рівень 0.5 при D = 41.2 пікс.
- Собель і Шарр (Шарр /4): середня різниця G 2.43; кут діагоналі 45.6° та 45.4° (істинний 45°).
- Canny: 7482 / 7127 / 6774 пікс. країв для порогів [30, 90] / [60, 180] / [120, 360]; пороги варіанта лишають лише найконтрастнішу подряпину.

Докладніше з графіками та висновками — у `lab11_fft2d_edges.ipynb`.
