# Лабораторна робота №6. Базові операції з цифровими зображеннями, аналіз каналів та колірні простори

**Дисципліна:** Обробка сигналів та зображень
**Виконав:** Афанасьєв Сергій, група КІ 24-1
**Варіант:** 2

## Мета

 Опанувати практичні навички програмного представлення цифрових растрових зображень як багатовимірних масивів даних у середовищі Python, дослідити відмінності структур колірного кодування бібліотек OpenCV, Pillow та Matplotlib, вивчити математичні засади функціонування колірних просторів 
RGB, HSV та CIELab, а також реалізувати алгоритми декомпозиції колірних каналів і порогової сегментації об'єктів за спектральними характеристиками.

## Завдання (варіант 2)

| Цільовий об'єкт | Нижня межа [H, S, V] | Верхня межа [H, S, V] | Застосування |
|-----------------|----------------------|-----------------------|--------------|
| Темно-червоний (Red Part 2) | [170, 120, 100] | [180, 255, 255] | Медичний аналіз крововиливів на знімках |

Межі подано в 8-бітній шкалі OpenCV (H: 0…180, S і V: 0…255). Тестова сцена 400×600 генерується в коді; до стандартних фігур я додав темно-червону пляму (BGR 50, 10, 190), яку виділяє діапазон варіанта 2.

## Запуск

Потрібен Python 3.10+.

```bash
python3 -m venv venv

# Windows (PowerShell)
venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python lab6_color_processing.py
```

Скрипт створює `data/test_image.png`, виводить у консоль параметри тензора, діапазони каналів HSV та Lab і площі масок, а графіки зберігає в `figures/`. Ноутбук `lab6_color_processing.ipynb` відкривається в Jupyter, VS Code або Google Colab; запускати його потрібно з каталогу проєкту.

## Короткі результати

- Зображення 400×600×3, `uint8`, 240000 пікселів, 703.1 КБ; піксель червоного круга: BGR [0, 0, 255], RGB [255, 0, 0].
- Формула півтонів BT.601 відрізняється від `cv2.cvtColor` не більше ніж на 1 рівень.
- Колір плями в HSV: H = 173, S = 242, V = 190 (потрапляє в діапазон варіанта 2); чисто червоний круг має H = 0 і в цей діапазон не потрапляє.
- Площі масок: варіант 2 — 6928 пікс. (2.89 %), червоний частина 1 — 9477 пікс. (3.95 %), повний червоний (`bitwise_or`) — 16405 пікс. (6.84 %); IoU з еталонною маскою плями 1.0000.

Докладніше з графіками та висновками — у `lab6_color_processing.ipynb`.
