# Лабораторна робота №7. Амплітудні перетворення, еквалізація гістограм та бінаризація методом Оцу

**Дисципліна:** Обробка сигналів та зображень
**Виконав:** Афанасьєв Сергій, група КІ 24-1
**Варіант:** 2

## Мета

Дослідити фундаментальні алгоритми поелементної амплітудної корекції монохромних цифрових зображень, опанувати математичні методи розрахунку та аналізу гістограм яскравості, реалізувати лінійне контрастування та нелінійну гамма-корекцію з використанням таблиць пошуку (LUT), засвоїти алгоритм глобальної еквалізації гістограм для розширення динамічного діапазону, а також порівняти ефективність глобальної порогової обробки, автоматичного методу міжкласової дисперсії Оцу та локальної адаптивної бінаризації на зображеннях із нерівномірним освітленням.

## Завдання (варіант 2)

| Тип зображення | k, b | γ₁, γ₂ | T_fixed | S, C |
|----------------|------|--------|---------|------|
| МРТ головного мозку | 1.8; −40 | 0.40; 2.5 | 95 | 15; 4 |

Знімка у завданні немає, тому використано синтетичний фантом МРТ 512×512 (низький контраст, нерівномірне освітлення, шум σ = 3), який генерується в коді.

## Запуск

Потрібен Python 3.10+.

```bash
python3 -m venv venv

# Windows (PowerShell)
venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python lab7_amplitude_processing.py
```

Скрипт створює `data/low_contrast_input.png`, виводить у консоль статистику зображень після кожного перетворення, пороги й частки білого та зберігає графіки в `figures/`. Ноутбук `lab7_amplitude_processing.ipynb` відкривається в Jupyter, VS Code або Google Colab; запускати його потрібно з каталогу проєкту.

## Короткі результати

- Вхідне зображення: діапазон 0…134, середнє 45.95, СКВ 36.24.
- Лінійне (k = 1.8, b = −40): діапазон 0…201, СКВ 55.34, відсічено 41.40 % пікселів знизу. Гамма 0.4: середнє 114.89; гамма 2.5: середнє 7.33.
- Вирівнювання гістограми: діапазон 0…255, СКВ 72.96, дисперсія зросла з 1313.0 до 5322.8; `cv2.equalizeHist` і `PIL.ImageOps.equalize` відрізняються максимум на 9 рівнів.
- Поріг Оцу T = 49 (збігається з власним перебором). Фіксований поріг 95 дає 2.46 % білого у лівій половині мозку проти 43.66 % у правій; адаптивні методи (S = 15, C = 4) дають 85.45 % та 84.88 %.
