# Лабораторна робота №9. Геометричні афінні та перспективні перетворення зображень

**Дисципліна:** Обробка сигналів та зображень
**Виконав:** Афанасьєв Сергій, група КІ 24-1
**Варіант:** 2

## Мета

Засвоїти теоретичні засади та матричний апарат просторових геометричних перетворень цифрових растрових зображень на основі однорідних координат, опанувати алгоритми афінних трансформацій (масштабування, перенесення, обертання та зсуву), дослідити вплив різних методів двовимірної інтерполяції яскравості на якість трансформованого кадру, а також реалізувати алгоритм усунення перспективних спотворень і проективного випрямлення об'єктів на основі матриці гомографії за чотирма опорними точками.

## Завдання (варіант 2)

| Об'єкт | θ, ° | s | tx | ty | Вершини [P1, P2, P3, P4] | W_out × H_out |
|--------|------|---|----|----|--------------------------|---------------|
| Текстовий документ на столі | −20 | 0.90 | −30 | 40 | [[180, 80], [620, 130], [710, 510], [70, 470]] | 500 × 350 |

Вихідний кадр 800×600 пікселів. Фотографії у завданні немає, тому сцену з перспективно спотвореним документом згенеровано в коді (істинний плаский документ відомий, що дозволяє оцінити точність виправлення).

## Запуск

Потрібен Python 3.10+.

```bash
python3 -m venv venv

# Windows (PowerShell)
venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python lab9_geometric_transforms.py
```

Скрипт створює `data/perspective_scene.png`, виводить у консоль матриці M та H, їхні перевірки й таблицю порівняння інтерполяцій, а графіки зберігає в `figures/`. Ноутбук `lab9_geometric_transforms.ipynb` відкривається в Jupyter, VS Code або Google Colab; запускати його потрібно з каталогу проєкту.

## Короткі результати

- Матриця M (2×3) = [[0.8457, −0.3078, 124.0561], [0.3078, 0.8457, −36.8443]], det лінійної частини 0.81 = s². Вершина P3 після перетворення виходить за межі кадру (y = 613.0).
- Власне зворотне відображення (білінійне) відрізняється від `cv2.warpAffine` не більше ніж на 1.26 рівня.
- Інтерполяція (збільшення у 2 рази): CUBIC та LANCZOS4 дають найкращу точність відновлення (20.3 дБ проти 19.6–19.8 дБ у NEAREST та LINEAR); LANCZOS4 найповільніший.
- Гомографія H (3×3), det(H) = 1.5666; власне розв'язання системи 8×8 збігається з OpenCV (2.8·10⁻¹⁴), образи вершин збігаються з кутами прямокутника; виправлений документ проти оригінала: PSNR 29.39 дБ.
