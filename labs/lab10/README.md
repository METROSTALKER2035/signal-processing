# Лабораторна робота №10. Математична морфологія бінарних та напівтонових зображень

**Дисципліна:** Обробка сигналів та зображень
**Виконав:** Афанасьєв Сергій, група КІ 24-1
**Варіант:** 2

## Мета

Дослідити теоретичні засади математичної морфології як інструменту нелінійної просторової обробки зображень, опанувати геометричні операції над множинами пікселів (ерозію, діляцію, морфологічне відкриття та закриття), вивчити вплив форми й розміру структуруючого елемента на структурну фільтрацію шумів та сегментацію, а також реалізувати конвеєри виділення контурів за допомогою морфологічного градієнта та компенсації нерівномірного фону за допомогою перетворень Top-Hat і Black-Hat.

## Завдання (варіант 2)

| Параметр | Значення |
|----------|----------|
| Структуруючий елемент | MORPH_RECT 5×5 |
| Кількість ітерацій | 1 |
| Ширина доріжки | 12 пікс. |
| Пороги Black-Hat / Top-Hat | 40 / 40 |
| Конвеєр | Closing → Black-Hat |

Знімка плати у завданні немає, тому кадр 600×400 (чотири доріжки, вісім розривів шириною 2, 7, 3, 5, 4, 9, 4, 3 пікс., шум «сіль» і «перець», півтоновий варіант з нерівномірним освітленням і пилом) згенеровано в коді; ідеальна топологія відома, тому якість очищення вимірюється.

## Запуск

Потрібен Python 3.10+.

```bash
python3 -m venv venv

# Windows (PowerShell)
venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python lab10_morphology.py
```

Скрипт створює тестові кадри в `data/`, виводить у консоль СЕ, площі, кількість компонент, таблицю виявлених розривів, а графіки зберігає в `figures/`. Ноутбук `lab10_morphology.ipynb` відкривається в Jupyter, VS Code або Google Colab; запускати його потрібно з каталогу проєкту.

## Короткі результати

- Ерозія 5×5 зменшує площу на 37.0 % (33239 → 20950 пікс.), діляція збільшує на 42.0 % (до 47192 пікс.); діляція закриває розриви до 4 пікс.
- Відкриття і закриття ідемпотентні; окреме відкриття збільшило кількість хибних пікселів (523 проти 357), послідовність «закриття, потім відкриття» дала 4 компоненти й 218 хибних пікселів.
- Морфологічний градієнт: 9928 пікс. = 4972 (зовнішній) + 4956 (внутрішній).
- Closing → Black-Hat з RECT 5×5 виявляє 5 з 8 розривів (усі ≤ 4 пікс., ширші — ні); СЕ 11×11 виявляє 8 з 8, але дає 2 хибні компоненти.
- Top-Hat знайшов 14 з 14 внесених крапок пилу.
