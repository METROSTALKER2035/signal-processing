# Лабораторна робота №4. Синтез цифрових КІХ та НІХ фільтрів та аналіз стійкості у z-площині
**Дисципліна:** Обробка сигналів та зображень
**Виконав:** Афанасьєв Сергій, група КІ 24-1
**Варіант:** 2

## Мета

Опанувати теоретичні засади z-перетворення для опису лінійних стаціонарних дискретних систем, дослідити зв'язок між конфігурацією нулів і полюсів передавальної функції на комплексній z-площині та амплітудно-частотними (АЧХ) і фазочастотними (ФЧХ) характеристиками, засвоїти алгебраїчні та геометричні критерії стійкості систем, а також набути практичних навичок проектування цифрових фільтрів зі скінченною (КІХ) та нескінченною (НІХ) імпульсними характеристиками й виконання фільтрації зашумлених вимірювальних сигналів.

## Завдання (варіант 2)

Базова система: `H(z) = (b0 + b1·z⁻¹ + b2·z⁻²) / (1 + a1·z⁻¹ + a2·z⁻²)`, `[b0, b1, b2, a1, a2] = [0.15, 0.3, 0.15, -0.8, 0.64]`.

| Фільтр | fs, Гц | fc, Гц | N_КІХ | N_НІХ | A1, В | f1, Гц | A2, В | f2, Гц | σ, В |
|--------|--------|--------|-------|-------|-------|--------|-------|--------|------|
| ФВЧ | 1200 | 350 | 51 | 4 | 2.0 | 100 | 1.5 | 450 | 0.30 |

Для ФВЧ складова f1 = 100 Гц є завадою, f2 = 450 Гц — корисним сигналом. Нестійкий аналог для порівняння: `a = [1, -1.2, 1.44]` (полюси з |p| = 1.2).

## Запуск

Потрібен Python 3.10+.

```bash

venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python lab4_filters_zplane.py
```

Скрипт виводить у консоль нулі та полюси систем, коефіцієнти фільтрів, значення АЧХ та групової затримки й оцінку придушення завади, а графіки зберігає в `figures/`. Ноутбук `lab4_filters_zplane.ipynb` відкривається в Jupyter, VS Code або Google Colab; запускати його потрібно з каталогу проєкту.

## Короткі результати

- Базова система: подвійний нуль z = −1, полюси 0.4 ± 0.6928j (|p| = 0.8, кут 60°), стійка; H(1) = 0.7143. Нестійкий аналог (|p| = 1.2): |h[29]| = 70.06 проти 9.4·10⁻⁴ у стійкої.
- КІХ (51 коеф., вікно Хеммінга): лінійна фаза, затримка 25 відліків; НІХ (Баттерворт 4-го порядку): стійкий, полюси |p| = 0.2385 та 0.6784.
- АЧХ на 100 / 300 / 450 Гц: КІХ −62.15 / −54.85 / −0.01 дБ, НІХ −54.89 / −9.69 / −0.03 дБ; на fc: КІХ −6.10 дБ, НІХ −3.03 дБ.
- Придушення завади 100 Гц: КІХ 60.02 дБ, НІХ 56.84 дБ; корисна складова 450 Гц зберігається на 99.94 % та 100.00 %. У НІХ фазовий зсув на 450 Гц 1.481 рад.
