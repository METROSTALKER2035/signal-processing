# Лабораторна робота №8.Просторова фільтрація зображень: згладжування, шумозаглушення та підкреслення меж

**Дисципліна:** Обробка сигналів та зображень
**Виконав:** Афанасьєв Сергій, група КІ 24-1
**Варіант:** 2

## Мета

Дослідити математичні засади та алгоритми двовимірної просторової фільтрації на основі операцій згортки та кореляції матриць, вивчити властивості лінійних згладжувальних фільтрів (усереднюючого та Гаусового), опанувати методи нелінійної фільтрації (медіанного та білатерального фільтрів) для селективного придушення імпульсного та флуктуаційного шумів, провести кількісну оцінку якості реставрації за критеріями MSE та PSNR, а також реалізувати підвищення різкості контурів за допомогою дискретного оператора Лапласа.

## Завдання (варіант 2)

| σg | p_sp | K_box, K_G, K_med | σ Гауса | Bilateral (d, σc, σs) | k_sharp |
|----|------|-------------------|---------|-----------------------|---------|
| 25.0 | 0.08 | 5×5, 5×5, 5 | 1.5 | 9, 80, 80 | 0.60 |

Еталонна сцена 400×600 генерується в коді; шуми відтворюються через `np.random.seed(42)`. Використано параметри варіанта 2 (у прикладі на сторінці σc = σs = 75).

## Запуск

Потрібен Python 3.10+.

```bash
python3 -m venv venv

# Windows (PowerShell)
venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python lab8_spatial_filters.py
```

Скрипт створює `data/reference_pattern.png`, виводить у консоль таблицю MSE та PSNR для всіх фільтрів і шумів, а графіки зберігає в `figures/`. Ноутбук `lab8_spatial_filters.ipynb` відкривається в Jupyter, VS Code або Google Colab; запускати його потрібно з каталогу проєкту.

## Короткі результати

- Гаусів шум: MSE 601.43 (20.34 дБ); «сіль та перець»: MSE 1691.60 (15.85 дБ).
- Гаусів шум після фільтрації (MSE): Bilateral 106.11, Median 241.93, Gauss 299.59, Box 374.40.
- Імпульсний шум після фільтрації (MSE): Median 217.45, Gauss 388.74, Box 452.92, Bilateral 612.56.
- Оператор Лапласа (k = 0.60): максимальний градієнт Собеля 872 → 1140; без попередньої фільтрації підвищення різкості підсилює шум (MSE 8701.75 проти 518.84 після білатеральної фільтрації).
